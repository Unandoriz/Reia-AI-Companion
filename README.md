# Reia AI Companion

Компаньон с искусственным интеллектом, который живёт на вашем компьютере:
помнит разговоры, меняется со временем и говорит вслух.

An AI companion that lives on your computer: it remembers conversations,
changes over time and speaks aloud.

**Установщик для Windows — на странице [выпусков](../../releases/latest).**
Приложение обновляется само: о новой версии оно узнаёт отсюда.

**The Windows installer is on the [releases](../../releases/latest) page.**
The app updates itself from here.
